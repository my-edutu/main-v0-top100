# Admin member email

In Admin → Awardees, choose Contact on a row or select records and choose Contact selected. The dialog first checks actual account emails, duplicate addresses, missing addresses, earlier daily attempts and unresolved deliveries. Review the welcome or reminder template for any selected person, then send only to eligible recipients. No codes or emails are created by this review. Each recipient gets a separate message; recipient addresses are read on the server. Linked account emails take priority for activated members. Unactivated awardees receive a newly issued, email-bound, single-use code valid for seven days.

Apply `supabase/migrations/20261106120000_admin_member_contact.sql` to the active self-hosted Supabase on Dokploy before using this feature. Configure `BREVO_SMTP_LOGIN`, `BREVO_SMTP_KEY`, `BREVO_SENDER_EMAIL`, `BREVO_SENDER_NAME`, and optionally `BREVO_SMTP_HOST` / `BREVO_SMTP_PORT` (defaults: smtp-relay.brevo.com / 587). The sender must be verified in Brevo. Set `TOP100_SITE_URL` to the public HTTPS site origin. No new worker schedule is needed.

The admin browser sends one request per selected record sequentially and must remain open. Results distinguish SMTP acceptance, rejection, skipped records and uncertain delivery. Pause after the current recipient or continue only the unattempted recipients. A synchronous send lock prevents repeated clicks. Sending rechecks the reviewed email and activation status; changed recipients are skipped. Acceptance does not prove inbox delivery. A durable daily reservation prevents double clicks or reloading from resending the same recipient on the same UTC day. No automatic retries occur. A network interruption stops the batch and marks that recipient uncertain in the dialog. Continue excludes every previously attempted recipient, including uncertain and rejected deliveries. Closing the dialog ends this browser session; reopening checks the durable database reservations again. Changing filters removes hidden awardees from the selection. The dialog accepts up to 500 selected awardees.

Attempts with `sending` or `unknown` status block further sends until reviewed. Check Brevo SMTP logs, then have an operator reconcile that attempt to `accepted` or `not_sent` in `admin_member_contact_attempts`; never clear an uncertain attempt without checking the provider. This table is restricted to the service role. It does not store codes or message bodies. Codes are stored in the existing access_codes table.
