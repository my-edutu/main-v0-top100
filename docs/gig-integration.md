# GIG Logistics integration

The app now uses GIG's documented third-party API for Nigerian award delivery:

- `POST /login` with `{ email, password }`
- authenticated requests with the `access-token` header
- `POST /price` for delivery quotes
- `POST /capture/preshipment` for shipment creation
- `GET /track/mobileShipment?Waybill=...&fetchOption=1` for tracking

GIG's test base URL is `https://dev-thirdpartynode.theagilitysystems.com`. The production base URL is
`https://thirdpartynode.theagilitysystems.com`. See the [official login reference](https://gig-logistics.readme.io/reference/post_login),
[price reference](https://gig-logistics.readme.io/reference/post_price),
[capture reference](https://gig-logistics.readme.io/reference/post_capture-bulk-preshipment), and
[tracking reference](https://gig-logistics.readme.io/reference/get_track-mobileshipment).

## Configure the test account

Copy the GIG section from `.env.example` into the server environment. Put the password only in your local secret store or deployment environment; do not commit it and do not prefix it with `NEXT_PUBLIC_`.

Required for test quotes:

```dotenv
GIG_ENABLED=false
GIG_API_BASE_URL=https://dev-thirdpartynode.theagilitysystems.com
GIG_API_USERNAME=<the test email supplied by GIG>
GIG_API_PASSWORD=<the test password supplied by GIG>
GIG_SENDER_NAME=<your business name>
GIG_SENDER_PHONE=<pickup phone>
GIG_SENDER_ADDRESS=<pickup address>
GIG_SENDER_CITY=<pickup city>
GIG_SENDER_LATITUDE=<pickup latitude>
GIG_SENDER_LONGITUDE=<pickup longitude>
GIG_SENDER_STATION_ID=<GIG sender station id>
# Leave GIG_RECEIVER_STATION_ID empty in production. It is resolved per user.
```

`GIG_ENABLED=false` keeps checkout on manual pricing while the account is being verified. Set it to `true` only after a successful quote and one controlled test shipment. The adapter also refuses to invent a quote when GIG returns an error, an unknown amount, or a non-NGN currency.

The existing award flow calls `getCourier().quote()` during checkout, calls `book()` after successful payment, and calls `track()` from the member tracking route. The password and access token are kept server-side and are never returned to the browser.

The sender station is fixed because it is your pickup location. The receiver station is calculated per customer by loading GIG's station directory and matching the customer's submitted state and city. For cities with multiple GIG stations, add an explicit mapping such as `GIG_RECEIVER_STATION_MAP_JSON={"lagos:victoria island":349}` after confirming the correct station with GIG. If there is no unique safe match, the order goes to manual pricing.

## Postman test sequence

Use the same base URL and credentials in Postman, then test in this order:

1. `POST {{baseUrl}}/login` with `{"email":"{{email}}","password":"{{password}}"}`. Save the returned access token.
2. `POST {{baseUrl}}/price` with the body generated by the app's quote adapter. Confirm the response amount and that it is in naira.
3. `POST {{baseUrl}}/capture/preshipment` once, using the documented `SenderDetails`, `ReceiverDetails`, `ShipmentDetails`, and `ShipmentItems` shape. Confirm exactly one waybill in the GIG dashboard.
4. `GET {{baseUrl}}/track/mobileShipment?Waybill={{waybill}}&fetchOption=1`.

Do not retry shipment creation. A retry can create a duplicate parcel. The app therefore retries login, quote, geocoding, and tracking, but never retries booking except for one safe re-login after a 401.

## Important account values

GIG requires station ids and coordinates for pricing/booking. Confirm these with GIG rather than relying on the placeholder station id. Vehicle types are numeric: bike `1`, van `2`, truck `3`, car `0`. The default shipment type is regular `1`.

If GIG's response field names differ for your account, use the `GIG_FIELD_*` overrides documented in `.env.example` rather than changing application code.

## Rollback

Unset any one of `GIG_API_BASE_URL`, `GIG_API_USERNAME`, or `GIG_API_PASSWORD`, or set `GIG_ENABLED=false`. The app immediately falls back to manual courier handling.
